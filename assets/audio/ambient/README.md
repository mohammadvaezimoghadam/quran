# Ambient Audio Files
Ultra-calm, peaceful background tracks for Quran recitation:
- `calm_melody.mp3` (نوای آرامش - امبینت آرام‌بخش بدون ریتم تند)
- `rain.mp3` (نم‌نم باران - بارش بسیار ملایم و یکنواخت بدون طوفان و رعد)
- `nature.mp3` (طبیعت و پرندگان - اتمسفر ملایم جنگل و آواز پرندگان سحرگاهی)
- `serenity.mp3` (نسیم آرامش - نوای ملایم بی‌کلام تلگرام)
- `deep_peace.mp3` (آرامش درون - پد اتمسفریک عمیق و طنین تدبر)
- `heavenly_melody.mp3` (نغمه ملکوت - هارمونی معنوی و روح‌بخش)
