## ۷. ساختار پیشنهادی مدل داده برای توسعه (Data Model Schema)

```dart
enum DuaCategoryType {
  keyDuas,
  keyZiyarats,
  atabatAliyat,
  qadrNights,
  ramadanDuas,
}

class DuaEntity {
  final String id;
  final String title;
  final String arabicTitle;
  final String? subtitle;
  final String? description;
  final DuaCategoryType category;
  final List<DuaPhraseEntity> phrases;
  final List<DuaReciterEntity> availableReciters;
}

class DuaPhraseEntity {
  final int index;
  final String arabicText;
  final String persianTranslation;
  final int? audioStartMs;
  final int? audioEndMs;
}
```
